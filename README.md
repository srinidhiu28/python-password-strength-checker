# 🔐 Password Strength Checker

## 📌 About the Project
Password Strength Checker is a Python program that
evaluates a password using predefined validation rules.

It checks whether the password meets requirements
such as minimum length and character variety.

## ✨ Features
- Minimum length validation
- Lowercase letter checking
- Uppercase letter checking
- Digit checking
- Special character checking
- Password strength feedback

## 🛠️ Technologies Used
- Python 3
- Regular Expressions (re module)

## ▶️ How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the terminal in the project folder.
4. Run:

   python password_checker.py

## 📚 Concepts Learned
- Functions
- Conditional Statements
- Loops
- Regular Expressions
- String Validation
- User Input

## 🔒 Security Note
This project is for educational purposes.
It does not store or transmit passwords.
